## 2024-05-24 - Argument Injection in Plugin Install Command
**Vulnerability:** Argument injection vulnerability where user-provided input `package` intended as a positional argument was directly concatenated into a `subprocess.run` command list (`["uv", "pip", "install", "--python", sys.executable, package]`). If the `package` string began with `-` or `--`, it would be interpreted as an option to the command (e.g., `--help` or potentially more dangerous options).
**Learning:** Even when using a list of arguments for `subprocess.run` (which prevents shell injection), user-controlled input can still manipulate the underlying command's behavior if it's evaluated as an option/flag instead of a positional argument. In command line interfaces, positional arguments that might look like flags need explicit separation.
**Prevention:** To prevent argument injection when executing subcommands via `subprocess.run` with user-provided input intended as a positional argument, always use the `--` separator to explicitly delineate options from positional arguments (e.g., `["uv", "pip", "install", "--python", sys.executable, "--", package]`).

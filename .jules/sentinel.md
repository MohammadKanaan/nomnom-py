## 2024-05-18 - Argument Injection in Command Execution
**Vulnerability:** Potential argument injection in `plugin_install_command` when passing user input directly to `subprocess.run` as a positional argument. A malicious user could supply an argument starting with `-` to inject options like `-r` into the `uv pip install` command.
**Learning:** Even if the underlying tool (like `uv`) might have some parsing defenses (e.g., rejecting `-r` as an invalid package name), passing unvalidated user input intended as a positional argument directly to a command runner opens the door to argument injection attacks if the tool's parsing behavior changes or if it interprets the input as an option before validation.
**Prevention:** To prevent argument injection when executing subcommands via `subprocess.run` with user-provided input intended as a positional argument, always use the `--` separator to explicitly delineate options from positional arguments (e.g., `["uv", "pip", "install", "--python", sys.executable, "--", package]`).

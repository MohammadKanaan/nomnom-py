## 2025-02-28 - Subprocess Argument Injection in CLI Command Execution
**Vulnerability:** The application used `subprocess.run` to execute package installation commands (`uv pip install`) where user input was supplied as a positional argument. By providing malicious flags in the package name string (like `-r malicious.txt` or `-c malicious.txt`), a user could inject options that execute unintended files or commands.
**Learning:** Argument injection occurs when an untrusted string meant to be a positional argument is interpreted as a command flag by the subprogram because it starts with `-` or `--`. When executing subcommands that parse flags via `subprocess.run`, appending the `--` separator is necessary to ensure all subsequent strings are strictly treated as positional arguments and not flags.
**Prevention:** Always delineate subprogram options from positional arguments with the `--` separator when calling external processes with user-supplied data as positional arguments (e.g., `["uv", "pip", "install", "--", package]`).
